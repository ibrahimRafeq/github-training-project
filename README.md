# github-training-project

Project Title: Smart Bureij
*************************************


Project Description: 
It is a smart application designed to improve municipal services in Al-Bureij Municipality by providing a digital platform that facilitates citizens' access to services, submission of reports, tracking of requests, and obtaining information quickly and efficiently.
The application contributes to enhancing digital transformation within the municipality, reducing paperwork, and improving communication between citizens and government officials.
************************************

1.Frontend:
Flutter (Cross-platform UI Framework)
